این داشبورد مدیریتی نمونه‌کاری با استفاده از دیتاست adventure works 2019 هست و استفاده از این دیتاست به دلیل کامل بودن و استاندارد بودن آن است که از هرگونه محدودیتی در اجرای عملیات فنی جلوگیری کند. 
و به جهت افزایش پرفورمنس و جلوگیری از بارگذاری داده اضافه، استخراج هدفمند اطلاعات موردنیاز در سطح sql و پیش از ورود به power bi انجام شده. 

برای سادگی، ویدئویی با طول 1:20 دقیقه : BI_Demo
و برای جزئیات، فایل .pbix پروژه : BI_Portfolio
در دسترس قرار دارند.
